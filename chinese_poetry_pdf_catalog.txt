中国古典诗词 PDF 文库：构建说明

完整 PDF 文件清单将在 GitHub Actions 构建完成后，自动写入发布包内的 dist/chinese_poetry_pdf_catalog.txt。

如何生成：
1. 打开 https://github.com/sia1915/chinese-poetry-pdf-library/actions/workflows/build-pdfs.yml
2. 点击 Build and publish poetry PDFs。
3. 点击 Run workflow 并确认。
4. 等待工作流完成。
5. 前往 https://github.com/sia1915/chinese-poetry-pdf-library/releases 下载 chinese-poetry-pdf-library.zip。

本文件是构建前的说明，不代表 PDF 二进制文件已经上传。
